# 2. Представление данных: Чистые символьные числа Черча

## Статус
Предложено (Proposed)

## Контекст
Большинство практических вычислительных сред жестко разделяют логические структуры управления и примитивные типы данных (такие как `int32`, `float`), перекладывая арифметические операции на аппаратное арифметико-логическое устройство (АЛУ) процессора. Это создает схоластический раскол между чистой логикой процесса и материальным представлением данных в памяти.

## Решение
Мы полностью запрещаем использование нативных аппаратных числовых типов и битовых масок на гостевом (объектном) уровне виртуальной машины.

1. **Структурное кодирование**: Все числовые значения и операции над ними (например, вычисление факториала) будут представлены исключительно в виде **чисел Черча** — то есть через пространственную вложенность структур комбинаторных функций. Число будет определяться как кратность повторения действия.
2. **Изоляция мета-уровня**: Использование нативных чисел процессора (через встроенные целые числа Chez Scheme) допускается *исключительно* на мета-уровне (в самом движке управления ВМ). Они будут применяться только для оптимизации счетчиков обхода указателей и проверки валентности активных комбинаторов. Вычисляемая программа внутри графа остается абсолютно символьной.

## Последствия
* **Положительные**:
  * Практическое доказательство концепции чистых символьных вычислений без зависимости от аппаратного АЛУ.
  * Настоящее архитектурное единство: функция факториала — это просто саморазворачивающаяся топологическая сеть понятий.
* **Отрицательные**:
  * Колоссальные вычислительные затраты и раздувание памяти при симуляции больших чисел по сравнению с нативными бинарными операциями процессоров Intel/AMD.
